Questions

Why is it free?

Because the work happens on your computer, each image costs nothing to process. There are no servers to pay for and nothing to sell.

Can I use the results commercially?

Yes, with the default models: BiRefNet is MIT-licensed and ViTMatte is Apache-2.0. The in-browser fallback (RMBG-1.4), used only when the local server isn’t running, is licensed for non-commercial use.

Can my team use one shared install?

Yes — run the server on one machine with a GPU, started with HOST=0.0.0.0 ./start.sh so others on your network can reach it (by default it only listens to your own computer). It has no log-in built in, so only do this on a network you trust, or put your own authentication in front of it.

Are there any limits?

Only your hardware: input images are processed at up to 4096 px on the long side, and your history keeps up to 500 images (you choose the limit in My images).
