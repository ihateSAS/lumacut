Background removal for your app

The Lumacut SDK is a small ES module. Call one function, get back a PNG. Inference runs on the user’s device, so there are no keys, quotas or per-image fees.

Quick start

Copy the js/ folder into your project (or serve this site) and import the SDK:

import { removeBackground } from './js/sdk.js';

const input = document.querySelector('input[type=file]');
input.addEventListener('change', async () => {
  const png = await removeBackground(input.files[0]);
  document.querySelector('img').src = URL.createObjectURL(png);
});

input can be a File/Blob, an image URL (the host must allow CORS), an <img>, a <canvas> or an ImageBitmap. Calls are queued, so it’s safe to fire many at once.

Not using modules? Include <script type="module" src="js/sdk.js"></script> and use window.Lumacut.removeBackground().

Options

OptionDefaultDescription
format'image/png''image/png', 'image/webp' or 'image/jpeg' (JPEG gets a white fill).
backgroundtransparentAny CSS colour, or 'blur' to keep a blurred version of the original scene.
blur40Blur strength 1–100 when background: 'blur'.
cropfalseCrop the output tightly to the subject.
padding0.08Margin around the subject when cropping, as a fraction of the subject size.
ratiooriginalForce an aspect ratio (width ÷ height), e.g. 1 for square, 4/5 for portrait.
shadowfalseAdd a soft drop shadow under the subject.
size'full''full', 'half' or 'preview' (≈0.25 megapixels).
model'auto''birefnet' (BiRefNet + ViTMatte, needs the local server), 'rmbg' (in-browser) or 'auto'.
quality0.92Encoder quality for JPEG and WebP.
 
// Square product shot on white with a shadow, as JPEG
const jpg = await removeBackground(file, {
  format: 'image/jpeg', background: '#ffffff',
  crop: true, padding: 0.1, ratio: 1, shadow: true,
});

Progress events

With the local server running (./start.sh), images go through BiRefNet + ViTMatte on your GPU; otherwise RMBG-1.4 downloads on first use (~45–176 MB) and runs in the browser. Pick one explicitly with model: 'birefnet' or model: 'rmbg'. Subscribe to status updates to show progress, or call loadModel() early to warm up the in-browser model.

import { onStatus, loadModel } from './js/sdk.js';

onStatus(({ stage, progress, loaded, total, device }) => {
  // stage: 'idle' | 'loading' | 'ready' | 'processing' | 'error'
  console.log(stage, Math.round(progress * 100) + '%', device);
});
loadModel(); // optional pre-warm

Advanced

getMask(input) returns the raw alpha mask as a canvas. createProject(input, options) returns the same Project object the editor uses — change project.state and call project.toBlob() or project.renderToCanvas().

import { createProject } from './js/sdk.js';
const project = await createProject(file);
for (const color of ['#fde68a', '#93c5fd']) {
  project.state.bg = { ...project.state.bg, type: 'color', color };
  variants.push(await project.toBlob());
}

Server-side use

      
The bundled server (server.py) runs BiRefNet and ViTMatte with PyTorch on Apple GPUs (MPS), NVIDIA GPUs (CUDA) or the CPU. POST /api/matte takes an image (JPEG/PNG body) and returns a grayscale PNG alpha matte at up to 1600 px; GET /api/status reports loading / warming / ready plus per-stage timings. To expose it publicly, put your own auth in front of it and run it on a GPU machine.
